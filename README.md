# MSA 手牌記錄器

在 Chrome 本機記錄 Mobile Suit Arena 中**自己可見的手牌**與**雙方公開的 Battle Log**。對戰小窗整合完整牌組卡列、已存手牌、雙方公開使用次數與同版本人工戰績；賽後可標記快照、整理牌組版本，再備份或匯出報告。

**[版本下載頁](https://github.com/tingwei1111/msa-hand-recorder/releases)** · [完整使用教學](docs/使用教學.md) · [版本紀錄](CHANGELOG.md)

本文件說明 **v0.7.0 公開測試版（Prerelease）**；安裝檔以 Releases 實際提供的版本為準。**尚未完成真人整場對戰的端到端驗證**，請先用測試對局人工核對卡號、張數、回合與公開 Log。

## 安裝到 Chrome

1. 從 [Releases](https://github.com/tingwei1111/msa-hand-recorder/releases) 的 **Assets** 下載版本 ZIP，例如 `msa-hand-recorder-v0.7.0.zip`；原始碼也可由專案首頁 **Code → Download ZIP** 取得。
2. 解壓到會保留的固定資料夾；不要直接載入 ZIP，安裝後也不要移動或刪除資料夾。
3. 在 Chrome 開啟 `chrome://extensions`，啟用「開發人員模式」。
4. 按「載入未封裝項目」，選擇解壓後的 **`extension` 子資料夾**。
5. 釘選「MSA 手牌記錄器」，並在開局前重新整理 MSA 分頁。

一般使用不需要 Node.js。官方卡片查詢沿用 `www.gundam-gcg.com` 網站權限；完整牌組追蹤不需要新增權限或 MSA 私有後端存取。

## 一場對局怎麼用

1. **準備牌組：**先到「資料與牌組」保存完整主牌 50 張的牌組版本，資源與 Token 分欄。
2. **開始記錄：**確認「自動記錄」已啟用，保留「自動收錄 Battle Log」，手牌位置先用「自動：下方玩家手牌」。按「記錄自檢」確認目前 MSA 分頁已載入相同版本。
3. **打牌時：**本人手牌成功存入後，在小窗「牌組」選版本並按「確認綁定本場牌組」。核對卡列的三種數量、觀察時間與實際手牌；需要時查卡或「標記此刻」。待存與錯誤提示不能當作保存成功。
4. **賽後：**先保留 MSA 對局分頁，查看提醒並按「更新 Log」。在「對局回顧」保留合併相容段落，核對公開 Log 起尾、未校準回合與手牌缺口。
5. **整理與保存：**在「資料與牌組」確認本人結果與先後手；下載完整備份。若要閱讀或分享單場，可另由回顧頁匯出獨立 HTML、Markdown、JSON 或 CSV。

同一場跨重新整理的記錄段落可在回顧頁合併；原段落保留。小窗手牌只取**目前段落中，玩家來源相符且已成功儲存的觀察**，不拿舊段手牌代替，也不顯示對手隱藏手牌。

## 讀懂完整牌組卡列

| 欄位 | 代表什麼 |
| --- | --- |
| 牌表 | 本場綁定的凍結版本張數；主牌合計 50 張。 |
| 手牌 | 最近已存且可核對的完整觀察顯示張數；部分觀察用 `≥` 表示已辨識下限，未知用 `?`。 |
| 公開使用 | 已收錄且能辨認主要卡號的公開使用累計次數；同卡再次使用會再次計數。 |

公開使用次數可能多於牌表張數，部署的來源區域也可能未確認。Shield、回手、洗回及未知區域資訊尚不完整，不能用「牌表 − 手牌 − 公開使用」當作精確剩餘牌庫。牌表外觀察另行提示，不會自動改寫主牌表。

小窗依目前所綁**同一版本**顯示本人的人工戰績；未確認結果不列勝率分母。已人工確認結果的對局，如需更換凍結牌組，請到管理頁核對後修改。

## 備份與還原

「資料與牌組」→「下載完整備份」保存目前本機工作資料。匯入時選擇 JSON／獨立 HTML，先核對來源、筆數、衝突及估計寫入量，再按「確認匯入這些資料」。

- 相同資料或已保存的相同匯入副本會跳過；合法重複事件與不同記錄段落不因文字相同而刪掉。
- 衝突對局另存 ID，保留原 game／玩家身分；其他衝突原件可在「匯入原件與衝突副本」下載。
- 不匯入錄製設定、分頁狀態或小窗位置。HTML 只解析內嵌 JSON，不執行其中的程式。
- 寫入不是原子交易。容量不足或中斷可能只完成部分；依結果檢查已核對保存及未完成項目，**保留原始檔案**。

## 牌組與戰績的解讀

牌表支援 `數量x卡號`、`數量 卡號`、`卡號x數量`，合併同卡號後檢查主牌 50 張與同卡號最多 4 張。資源與 Token 分欄，不計入主牌。**格式通過不表示卡片存在、類型正確或符合當期禁限卡與賽制**。

修改會產生新版本，已綁定對局保存凍結牌表。手牌片段、Shield、回手及累計公開部署不會被拿來推算精確牌庫。

結果由使用者確認；對手投降選「勝」，本人投降選「本人投降（計負）」。同一 game／確認玩家只算一次。總勝率以確認的勝、負、和局、本人投降為分母；決勝勝率排除和局。未確認結果不列分母，並另列樣本數。兩者均可按牌組版本與先後手篩選。

## 資料保存、權限與限制

對局與工作資料存在目前 Chrome 使用者設定檔，沒有自動雲端同步。更新前先下載完整備份，再更新**原安裝路徑**中的檔案，於 `chrome://extensions` 重新載入原擴充功能；不要先解除安裝。下一場開局前重新整理 MSA 分頁並自檢。

記錄器只讀取 MSA 頁面已顯示的內容，不讀 cookie、不攔截 WebSocket、不請求 MSA 私有 API，也不替玩家出牌。官方查卡是額外的單卡公開資料請求，使用 `credentials: omit` 與 `no-referrer`，不附帶對局記錄；卡片資料只作短期記憶體快取，不占對局儲存空間。官方卡文與圖片不隨專案或安裝包整批提供。詳見[卡片資料來源](docs/card-sources.md)。

公開 Log 涵蓋、單次手牌辨識品質與手牌擷取缺口分開呈現。**Log 已見起尾、提醒已收起、自檢通過，都不代表手牌全程完整。**未觀察到的手牌無法補回；動畫、背景節流、休眠或關頁仍可能造成缺漏。

匯出檔包含自己的手牌、玩家名稱、筆記及人工戰績。分享前請檢查內容；本機保存不等於已匿名化。

## 本機開發與合成預覽

開發環境需要 Node.js 22 以上與 Python 3，沒有外部 npm 依賴。

```sh
npm test
npm run preview
```

開啟 `http://127.0.0.1:8768/demo/index.html`。合成示範包含對戰小窗、擴充功能小視窗、回顧頁與 `demo/library-preview.html` 管理頁，不使用真實對局或私有 Log。合成預覽不能代替真人整場驗證。

修改 HTML 後執行 `npm run preview:sync`；`npm run package` 產生安裝包。自動測試涵蓋資料隔離、匯入／保存邊界及合成流程，實際結果請以當次測試輸出為準。
